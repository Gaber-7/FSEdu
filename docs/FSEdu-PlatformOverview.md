# منصّة FSEdu — التوثيق الشامل للميزات

> **المنصّة:** نظام تعليمي ذكي (EdTech SaaS) للتعليم عن بُعد لطلاب المراحل الابتدائية والإعدادية في مصر.
> **التقنيات:** ‎.NET 9 · Blazor Server (Interactive) · SQL Server 2022 · EF Core 9 · SignalR · LiveKit Cloud · WebPush (VAPID).
> **المعمارية:** Clean Architecture (Domain → Application → Infrastructure → Presentation) مع MediatR/CQRS وFluentValidation وResult Pattern.

## 1. نظرة عامة

**FSEdu** منصّة تعليم إلكتروني عربية للمراحل الابتدائية والإعدادية. تقدّم:

- 🎥 **دورات مسجَّلة** بفصول ودروس متعدّدة الأنواع (مسجّل/مباشر/مذكرة/اختبار)
- 📡 **بثّ مباشر** بسبورة تفاعلية واستطلاعات ورفع يد وتسجيل تلقائي
- 📝 **اختبارات** متنوّعة (Quiz/Assignment/Exam) مع تصحيح آلي
- 💳 **اشتراكات** مرنة (شهري لمادة / تَرم لمادة / تَرم كامل لمرحلة) عبر إنستا باي/فودافون كاش/تحويل بنكي
- 🏆 **gamification** بـ XP وشارات وسلاسل ومتصدّرين
- 📱 **PWA + Push Notifications** بـ VAPID
- 🔍 **بحث موحّد** على الدورات والمدرّسين والمواد

## 3. ميزات الطالب

### 🏠 لوحة الطالب (`/dashboard/student`)

- ترحيب شخصي + شارة سلسلة الأيام المتواصلة 🔥
- KPI Cards: عدد الدورات المتاحة، الدروس، نقاط XP، أطول سلسلة
- 🎯 **مهمّة اليوم (Daily Mission):** 3 أهداف يومية محسوبة تلقائيًا
  - ▶ شاهد درسين
  - ✅ أكمل درسًا (≥ 90%)
  - 📝 حلّ اختبارًا
  - دائرة تقدّم + شريط لكل هدف + رسالة احتفال عند الإكمال
- ✨ **مقترح لك (Course Recommendations):** دورات في نفس المرحلة، مرتّبة بترتيب ذكي يعتمد على اهتمامات الطالب (المواد التي بدأ بها) ثم التقييم ثم عدد الملتحقين
- ▶ **تابع المشاهدة (Continue Watching):** بطاقات أفقية للدروس التي بدأها الطالب ولم يكملها، تعرض الموقع الفعلي + شريط تقدّم، النقر يستكمل من نفس النقطة
- شارة "اشترك الآن" إذا لم يكن لديه اشتراك فعّال
- ملخّص الاشتراك الحالي (نوع، تاريخ انتهاء، أيام متبقية)
- تحدّي الأسبوع + الواجبات

### 📚 الدورات (`/courses`)
- تصفّح مع فلتر بالمرحلة والمادة
- بطاقات بـ thumbnail/تقييم/عدد ملتحقين
- صفحة دورة كاملة (`/courses/{id}`):
  - Hero بمعلومات المدرّس وعدّاد الدروس
  - 🔖 زر "احفظ للرجوع" (للطلاب فقط)
  - 📣 **إعلانات الدورة** (يكتبها المدرّس، تصل push للجميع)
  - فهرس الفصول والدروس مع أيقونة حالة وعلامة "مجاني" للمعاينة
  - 📝 الاختبارات والواجبات
  - ⭐ **تقييمات ومراجعات** (5 نجوم + breakdown)
  - رابط ملف المدرّس العام

### 🎓 صفحة الدرس (`/lessons/{id}/watch`)
- مشغّل فيديو (HTML5 أو YouTube embed) مع watermark بالاسم والجوّال
- 🔖 **علامات الدرس (Lesson Markers):**
  - زر "احفظ هذه اللحظة" يقرأ موقع الفيديو تلقائيًا
  - حقل عنوان اختياري لكل علامة
  - قائمة بالعلامات: النقر يقفز للموقع
- 📎 **مرفقات الدرس:** PDF/Office/ZIP/صور/صوت بأيقونات حسب النوع
- 📝 **ملاحظاتي على الدرس:** textarea خاصة، حفظ تلقائي debounced (700ms) + حفظ فوري عند المغادرة
- ❓ **Lesson Q&A:** أسئلة الطلاب وردود المدرّس
- 🎬 **تتبّع تلقائي:**
  - كل 15 ثانية يُرسل الموقع والنسبة للسيرفر
  - عند الإيقاف أو مغادرة الصفحة (pagehide/beforeunload)
  - استكمال تلقائي من آخر موقع عند العودة

### 📅 جدولي (`/student/schedule`)
- agenda أسبوعية أو شهرية (تبديل 7/14/30 يوم)
- الحصص المباشرة + الاختبارات المتاحة معًا
- تجميع تلقائي بالأيام (اليوم / غدًا / أمس / اسم اليوم بالعربي)
- مؤشّر 🔴 "الآن" لحصة جارية + pulse effect
- زر "انضم" أو "ابدأ" مباشرة من كل عنصر

### 🎥 الحصص المباشرة (`/student/live`)
- قائمة الحصص القادمة + الحصص الجارية
- زر انضمام عند انطلاق الحصة
- داخل الغرفة:
  - فيديو/صوت LiveKit
  - 🖌️ **سبورة تفاعلية** مع ألوان وأقلام
  - 📊 **استطلاعات (Polls)**
  - ✋ **رفع يد** (Hands-raised queue)
  - 💬 شات للحصة
  - تسجيل صلاحيات (شاهد فقط أو شاهد + شاركك المدرّس)

### 📼 التسجيلات (`/student/recordings`)
- قائمة الحصص المسجّلة من الفصول السابقة
- مشغّل فيديو في الصفحة

### 📝 ملاحظاتي الموحّدة (`/student/notes`)
- كل الملاحظات على كل الدروس في صفحة واحدة
- بحث نصّي (يبحث في النص + اسم الدرس + اسم الدورة)
- تجميع بالدورة (كل دورة سكشن منفصل)
- إحصائية (إجمالي الملاحظات، عدد الدورات، نتائج البحث)

### 🔖 المحفوظات (`/student/bookmarks`)
- grid للدورات التي حفظها للرجوع لاحقًا
- زر "افتح" + "إزالة"

### 📈 تقدّمي (`/student/progress`)
- نسبة إكمال لكل دورة
- إجمالي الدروس المُكتملة من المتاحة
- أحدث درس ولـ XP والـ streak
- اقتراح إكمال للدورة الأقرب

### 📜 سجلّ نشاطي (`/student/activity`)
- timeline موحّدة من 6 مصادر:
  - ▶ دروس (شاهد/أكمل)
  - 🏆 شارات حصل عليها
  - 📝 اختبارات قدّمها
  - ❓ أسئلة سألها
  - ⭐ تقييمات كتبها
  - 💳 اشتراكات أنشأها
- tabs للتصفية حسب النوع
- تجميع بالأيام

### 🏆 إنجازاتي (`/student/achievements`)
- XP، الـ streak الحالية والأطول
- الترتيب العام والترتيب داخل المرحلة
- شبكة الشارات (المُكتسبة + المتاحة)
- زر تنزيل الشهادة لكل دورة مُكتملة

### 📊 المتصدّرون (`/leaderboard`)
- Top 50 طالب بـ XP
- فلتر بالمرحلة
- إبراز ترتيبك الشخصي

### 💳 اشتراكاتي (`/student/subscriptions`)
- قائمة الاشتراكات (نشطة/منتهية)
- 🔄 زر **تجديد** (يأخذك لـ Subscribe بالمعطيات السابقة)
- ⏳ تنبيه قبل انتهاء الاشتراك بـ 7 أيام (background service)

### 🛒 الاشتراك (`/subscribe`)
- 3 طرق دفع: إنستا باي 🏦، فودافون كاش 📱، تحويل بنكي 🏛️
- تعليمات تحويل لكل طريقة (الرقم/الـ IBAN/الرابط)
- رفع صورة الإيصال (JPG/PNG/PDF — 5MB)
- 🏷️ **حقل كود الكوبون:** تحقّق فوري + عرض الخصم + المبلغ النهائي
- ملاحظات اختيارية
- بعد الإرسال: الاشتراك Pending حتى يعتمد الأدمن الإيصال

### 💬 اسأل مدرس (`/student/tickets`)
- إرسال تذكرة دعم
- خيط محادثة (رد المدرّس/المشرف)
- حالة (مفتوحة/قيد الإجابة/تمّ الرد/مغلقة)

### 👤 ملفّي الشخصي (`/student/profile/edit`)
- تعديل الاسم
- إضافة/تعديل البريد الإلكتروني (يُلغى التفعيل عند تغيير العنوان)
- رقم الجوّال للقراءة فقط (يتطلّب OTP لتغييره عبر الدعم)
- معلومات أكاديمية للقراءة (المرحلة، المنطقة، المدرسة)
- إحصائيات الإنجاز

### 📝 تقديم اختبار (`/assessments/{id}/take`)
- شاشة بدء (المدة، عدد الأسئلة، الدرجة الكاملة)
- عدّاد تنازلي إن وُجد وقت محدّد
- التنقّل بين الأسئلة + شريط التقدّم
- تسليم → نتيجة فورية مع شرح كل سؤال

### 🎓 شهادة الإنجاز (`/student/courses/{id}/certificate`)
- شهادة HTML قابلة للطباعة كـ PDF
- اسم الطالب، اسم الدورة، المدرّس، تاريخ الإكمال، رقم تعريف فريد

## 4. ميزات المدرّس

### 🏠 لوحة المدرّس (`/dashboard/teacher`)
- KPI: عدد الدورات (منشورة/معلّقة/مسوّدة)، إجمالي الدروس، الالتحاق
- Live Analytics:
  - عدد الحصص الكلّي + هذا الأسبوع + جارية الآن + قادمة
  - عدد التسجيلات المتاحة
  - حضور فريد + إجمالي الدقائق + متوسط الحضور
- آخر 6 دورات + آخر 6 حصص

### 📚 دوراتي (`/teacher/courses`)
- قائمة دورات المدرّس
- زر "إنشاء دورة" (`/teacher/courses/create`)
- زر تعديل لكل دورة (`/teacher/courses/{id}/edit`):
  - بيانات الدورة (العنوان، الوصف، الـ thumbnail، السعر، المرحلة، المادة)
  - إضافة فصول
  - إضافة دروس داخل الفصل (Recorded/Live/Document/Quiz/Assignment)
  - رفع فيديو/مذكّرة
  - حذف فصل/درس
  - زر "Submit for Review" → الأدمن يعتمد

### 🎥 البثّ المباشر (`/teacher/live`)
- جدولة حصّة جديدة (`/teacher/live/schedule`):
  - العنوان، الوصف، المادة، المرحلة، موعد، مدة
- قائمة الحصص (مجدولة/مباشرة/منتهية)
- زر "ابدأ البثّ" يأخذك للـ live room
- داخل الـ live room:
  - شارة المدرّس (يستطيع التحدّث/الفيديو)
  - أدوات: 🎤 صوت، 📷 كاميرا، 🖥️ مشاركة شاشة
  - 🖌️ سبورة تفاعلية (لكل المشاركين)
  - 📊 إنشاء استطلاعات (سؤال + خيارات)
  - ✋ صفّ رفع اليد (يدعو الطلاب فردًا فردًا)
  - 🎙️ نداء طالب (يفتح ميكروفون مؤقت)
  - 📹 تسجيل (Recorder client-side يجمع الفيديو + الصوت + السبورة)
  - 🛑 إنهاء الحصة

### 📨 صندوق الأسئلة (`/teacher/qa-inbox`)
- كل أسئلة الطلاب على دروسه في مكان واحد
- tabs: "بانتظار الرد" / "الكل"
- لكل سؤال: اسم الدورة، اسم الدرس، اسم الطالب، نص السؤال، نموذج رد inline
- العدّاد أعلى الصفحة (بانتظار الرد / إجمالي)

### 📣 إعلان دورة
- داخل صفحة الدورة، نموذج إنشاء إعلان (عنوان + نص + خيار تثبيت 📌)
- يصل push notification لكل المسجّلين تلقائيًا
- زر حذف لإعلاناته

### ✏️ ملفّي الشخصي (`/teacher/profile/edit`)
- النبذة (Bio) — 2000 حرف
- سنوات الخبرة
- المؤهلات:
  - قائمة المؤهلات الحالية + زر حذف
  - نموذج إضافة (العنوان، الجامعة، السنة)
- زر "عرض الملف" يأخذه للـ public profile

### 🌐 الملف العام للمدرّس (`/teachers/{id}`)
- Hero بـ avatar، شارة "معتمد" ✓، تقييم بالنجوم
- المواد + المناطق
- النبذة
- الإحصائيات (دورات/دروس/طلاب/حصص/تسجيلات)
- قائمة المؤهلات
- شبكة الدورات المنشورة
- زر "تعديل ملفّي" يظهر للمدرّس فقط على ملفّه

### 📝 إنشاء اختبار (`/teacher/assessments/create`)
- العنوان، النوع (Quiz/Assignment/Exam)، المدة، الدرجة
- ربط بدورة معيّنة
- بنك الأسئلة:
  - أسئلة جديدة أو من بنك سابق
  - أنواع: اختيار من متعدّد، صح/خطأ، مقالي، رقمي
  - وزن لكل سؤال + شرح للإجابة

### 💬 التذاكر (`/staff/tickets`)
- التذاكر المُحالة للمدرّس (طلابه أو طلب توجيه)
- خيط محادثة كامل
- إغلاق التذكرة

## 6. ميزات الأدمن (إداري)

### ⚙️ لوحة الإدارة (`/admin/dashboard`)
- نظرة عامة شاملة:
  - إجمالي المستخدمين (طلاب/مدرّسين/أولياء)
  - الدورات (منشورة/معلّقة)
  - الإيرادات الشهرية
  - الدفعات المعلّقة
  - الحصص المباشرة هذا الأسبوع
  - الحصص الجارية الآن

### 👨‍🏫 اعتماد المدرّسين (`/admin/teachers/pending`)
- قائمة طلبات تسجيل المدرّسين المعلّقة
- بيانات كل مدرّس (الاسم، المؤهلات، المواد، المناطق)
- زر اعتماد → يصبح المدرّس Verified ✓ ويستطيع نشر دورات
- زر رفض مع سبب → يُرسل إشعار للمدرّس

### 📚 اعتماد الدورات (`/admin/courses/pending`)
- الدورات التي قدّمها المدرّسون للنشر
- معاينة كاملة (فصول/دروس)
- زر اعتماد → ينشر الدورة + إشعار للمدرّس
- زر رفض مع سبب

### 💳 اعتماد المدفوعات (`/admin/payments/pending`)
- قائمة الإيصالات المرفوعة من الطلاب
- صورة الإيصال، رقم العملية، المبلغ، نوع الاشتراك
- زر اعتماد → يُفعّل الاشتراك + إشعار للطالب
- زر رفض مع سبب → إشعار للطالب

### 🏷️ الكوبونات (`/admin/coupons`)
- قائمة الكوبونات (نشطة/منتهية/معطّلة)
- لكل كوبون: الكود، النسبة أو المبلغ، تاريخ الانتهاء، عدد الاستخدامات، الحد الأقصى
- زر "كوبون جديد":
  - الكود (إنجليزي وأرقام وشُرَط)
  - نوع الخصم (نسبة % أو مبلغ ثابت)
  - تاريخ انتهاء اختياري
  - أقصى عدد استخدامات اختياري
- زر "إيقاف" لتعطيل كوبون

### 📣 بثّ إشعار جماعي (`/admin/broadcast`)
- اختيار الجمهور:
  - 🌍 كل المستخدمين
  - 🎓 كل الطلاب
  - 👨‍🏫 كل المدرّسين
  - 👨‍👩‍👦 كل أولياء الأمور
  - 📚 طلاب مرحلة معيّنة
- العنوان + النص + رابط اختياري
- يصل عبر notifications + push لكل المُستهدفين

### 📨 الأسئلة والتذاكر (`/staff/tickets`)
- صندوق التذاكر الكلّي
- إحالة لمدرّس
- إغلاق

## 8. الميزات المشتركة

### 🔔 الإشعارات
- جرس في الـ Navbar مع badge للعدد غير المقروء (تحديث كل 30 ثانية)
- قائمة منسدلة بأحدث 8 إشعارات

## 9. المعمارية التقنية

### الطبقات
```
src/
├── Core/
│   ├── FSEdu.Domain         ← Entities + Value Objects + Domain logic
│   └── FSEdu.Application    ← CQRS Commands/Queries + Validators + Abstractions
├── Infrastructure/

├── Presentation/
│   ├── FSEdu.Api            ← Minimal API endpoints + SignalR Hubs
│   ├── FSEdu.Web            ← Blazor Server (Interactive)
│   ├── FSEdu.Web.Client     ← Blazor WASM (مكتبة مشتركة بسيطة)
│   └── FSEdu.Web.Shared     ← مكونات مشتركة
└── BuildingBlocks/
    ├── FSEdu.Shared.Kernel  ← Primitives (Entity, AggregateRoot, ValueObject, Result, Error)
    └── FSEdu.Shared.Contracts ← DTOs (لا entities) — مشاركة بين API و UI
```

### الأنماط المعتمدة
- **Clean Architecture** — اعتماديات داخل-خارج فقط
- **CQRS** عبر MediatR (ICommand/IQuery + Handlers)
- **Validation** عبر FluentValidation
- **Result Pattern** — لا exceptions للأعمال
- **Soft Delete** + **Auditing** عبر Interceptors
- **Repository غير مستخدم** — DbContext مباشرة في Handlers
- **EF Core 9 Migrations** — `MigrateAsync` تلقائي في dev

### 🧪 سيناريوهات الاختبار

#### السيناريو 1 — رحلة طالب جديد كاملة (15 دقيقة)
1. سجّل دخول كطالب
2. **لوحتي:** تحقّق من وجود مهمّة اليوم + مقترح لك + الإحصائيات
3. اذهب لـ `/courses` → اختر دورة → اضغط 🔖 احفظ → اضغط ⭐ تقييم
4. افتح درسًا → شاهد أول 30 ثانية → اضغط 🔖 احفظ هذه اللحظة بعنوان "مهم"
5. اكتب ملاحظة في القسم الخاص → غيّر التبويب → ارجع → تحقّق من حفظها
6. ارفع سؤالًا (Q&A) → اخرج
7. اذهب لـ `/student/notes` → تحقّق من الملاحظة
8. اذهب لـ `/student/bookmarks` → تحقّق من الدورة
9. اذهب لـ `/student/activity` → شاهد كل ما فعلته في الـ timeline
10. ارجع للوحة → تحقّق من تحديث Continue Watching

#### السيناريو 2 — رحلة مدرّس (10 دقائق)
1. سجّل دخول كمدرّس
2. **لوحتي:** راجع KPI
3. اذهب لـ `/teacher/qa-inbox` → جاوب على السؤال الذي طرحه الطالب
4. اذهب لـ `/teacher/courses` → اختر دورة → افتحها
5. اكتب إعلانًا (📣) — اختر "ثبّت في الأعلى"
6. اذهب لـ `/teacher/profile/edit` → غيّر النبذة → أضف مؤهلًا جديدًا
7. اذهب لـ `/teachers/{your-id}` → تأكّد أن التحديثات ظهرت
8. (اختياري) ابدأ حصة مباشرة من `/teacher/live`

#### السيناريو 3 — رحلة دفع كاملة (8 دقائق)
1. سجّل دخول كأدمن → اذهب لـ `/admin/coupons` → أنشئ كوبون `WELCOME25` (نسبة 25%)
2. سجّل خروج → ادخل كطالب
3. اذهب لـ `/pricing` → اختر اشتراك → اضغط "اشترك"
4. في صفحة `/subscribe`: اختر طريقة دفع → ارفع صورة (أي صورة)
5. أدخل الكوبون `WELCOME25` → اضغط تطبيق → تأكّد من ظهور الخصم
6. أرسل الطلب
7. سجّل خروج → ادخل كأدمن → اذهب لـ `/admin/payments/pending` → اعتمد الإيصال
8. ادخل كطالب → تحقّق من إشعار التفعيل في الجرس 🔔

#### السيناريو 4 — البثّ المباشر (15 دقيقة)
1. **متصفّح A (المدرّس):** سجّل دخول كمدرّس → اذهب لـ `/teacher/live` → ابدأ حصة قائمة أو جدول حصة جديدة بـ "الآن"
2. **متصفّح B (الطالب):** سجّل دخول كطالب → اذهب لـ `/student/live` → انضم
3. المدرّس: فعّل الكاميرا والميكروفون → فعّل السبورة → ارسم → أنشئ استطلاع
4. الطالب: ارفع يدك ✋ → استلم نداء المدرّس
5. المدرّس: ابدأ التسجيل → أوقف بعد دقيقة → ابدأ يحمّل الفيديو للسيرفر
6. أنهِ الحصة → اذهب لـ `/student/recordings` بعد قليل → افتح التسجيل

#### السيناريو 5 — Daily Mission + Streak (5 دقائق)
1. ادخل كطالب
2. شاهد أول درس حتى 90% → تحقّق من ظهوره مُكتمل في "تابع المشاهدة"
3. شاهد ثاني درس → افتح اللوحة → "مهمّة اليوم" تُظهر 2/3 مُكتمل
4. قدّم اختبارًا → ارجع → "مهمّة اليوم" تُظهر 3/3 → احتفال 🎉

#### السيناريو 6 — Admin Broadcast (3 دقائق)
1. ادخل كأدمن
2. اذهب لـ `/admin/broadcast`
3. اختر "كل الطلاب" → اكتب عنوان "🚨 تنبيه: صيانة الليلة" + نص + رابط `/dashboard/student`
4. أرسل
5. سجّل دخول كطالب → الجرس يظهر 1 إشعار جديد + إذا فعّل push يُظهر notification أصلي على نظام التشغيل

#### السيناريو 7 — استكمال الفيديو من نقطة التوقف (4 دقائق)
1. ادخل كطالب → افتح درسًا فيه فيديو
2. شاهد لمدة 60 ثانية → أوقفه عند الثانية 45
3. اخرج (أغلق التبويب)
4. ارجع للوحة → "تابع المشاهدة" يُظهر الدرس عند 00:45 / المدة الكاملة
5. اضغط الدرس → يُستكمل تلقائيًا من 00:45
